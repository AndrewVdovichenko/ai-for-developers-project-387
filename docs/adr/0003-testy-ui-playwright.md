# Тесты UI: Playwright e2e сейчас, Storybook позже

Интерфейс тестируем сквозными e2e-тестами Playwright (chromium, против собранного
`vite preview`, шаг `yarn test:e2e` в цепочке `check`) — это соответствует требованию
«тесты на главную страницу в GitHub Actions» и заранее покрывает следующий этап:
сценарий бронирования проходит через web и API сразу. Component-unit-тесты
(Testing Library + jsdom) сознательно не заводим. Storybook подключаем на этапе
календаря слотов и формы гостя, когда появится компонентная база для изолированной
разработки и сверки палитры в светлой и тёмной схемах.
