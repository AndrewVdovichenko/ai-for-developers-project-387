# Цветовая палитра: teal как primary

Основной цвет интерфейса — `teal` из встроенной палитры Mantine, зафиксированный семантически
в `apps/web/src/theme.ts`: primary — `teal` (CTA, активные элементы, выбранный слот),
success — `green` (подтверждение записи), error — `red` (занятый слот, ошибки формы),
warning — `yellow` (истекающее бронирование слота), нейтральные — `gray`. Тёмная схема
включена сразу через `defaultColorScheme="auto"`. Встроенные палитры Mantine дают
сбалансированные контрасты без ручного подбора hex.

## Considered Options

- `blue` — «календарная» классика, но выбран `teal` как отличимый цвет бренда;
- `violet` — ближе к Calendly, отклонён;
- кастомные hex — отклонены: потеря встроенных контрастов Mantine без выигрыша на этом этапе.
