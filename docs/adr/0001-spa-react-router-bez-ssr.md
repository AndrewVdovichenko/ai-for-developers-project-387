# Фронтенд — SPA на react-router без SSR

Фронтенд (`apps/web`) — статический SPA на Vite с маршрутизацией react-router в library-mode
(`createBrowserRouter` + `RouterProvider`). Гость приходит на страницу записи по прямой ссылке
владельца, а не из поиска, поэтому SEO и быстрый первый рендер не дают нам выгоды,
достаточной для отдельного SSR-сервера, гидрации и усложнения запуска; выбранный вариант проще
при уже существующем контракте API.

## Considered Options

- react-router framework mode с SSR — отклонён: лишний сервер рендеринга ради страниц,
  которые не находят через поиск.
- Пререндеринг/SSG — возвращаемся, если понадобятся превью ссылок в мессенджерах;
  альтернативно OG-мета может отдаваться API по URL типа встречи.
