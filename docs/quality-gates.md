# Проверка каркаса

Проверено локально 15 ноября 2026 года, macOS arm64.

## Результат

- `mise run setup`: установка по lock-файлу, генерация и подключение локальных hk-хуков.
- `mise run check`: полный прогон проверок, один HTTP-тест и сборка двух приложений.
- `mise run security:audit`: 482 пакета, известных уязвимостей не найдено.
- `mise run dev`: оба сервера запущены; проверены состояние, журналы и остановка.
- Chrome: интерфейс отрисован, кнопка вызывает SDK и показывает «Сервер доступен»;
  ошибок JavaScript не обнаружено.
- Pre-commit: проверены форматирование, линт и отказ на синтетическом секрете в индексе Git.

У каждой проверки подтверждён ненулевой код выхода на временном нарушении.
После проверки исходные файлы восстановлены; тестовые секреты и нарушения в Git не сохранены.

## Границы набора

Инструменты выбраны по [dev-quality-gates](https://github.com/mokevnin/dev-quality-gates).
Oxlint и oxfmt выполняют задачи линтера и форматтера; ESLint и Prettier дополнительно
не установлены. Stryker и собственные ast-grep-правила отложены до появления
бизнес-логики и конкретных требований. Отдельный Python-инструмент для схем
конфигурации не добавлен: используются валидаторы TypeSpec, hk и jactionlint,
а конфигурации TS-инструментов загружаются при каждом прогоне.

`strict` включён. Дополнительный `exactOptionalPropertyTypes` не включён:
сгенерированный Fetch-клиент Hey API 0.99.0 пока с ним несовместим.
Компилятор приложения — TS 7; TS 6 используется только как API совместимости
для генератора и анализатора импортов.

jactionlint работает офлайн, с отказом также на предупреждениях. ShellCheck
не подключён: workflow содержит только вызовы команд без shell-логики.
Исключение `duplicate-triggers` ограничено новым workflow и объясняется требованием
запуска на каждый push и pull request. Workflow Хекслета не изменён и не проверяется
новыми инструментами. Генерируемый код исключён из линта и форматирования,
но проверяется компилятором и повторной генерацией.

AGENTS.md отложен по договорённости. Новые workflow проверены локально;
удалённый прогон GitHub Actions состоится после push. Публикация изменений не выполнялась.
